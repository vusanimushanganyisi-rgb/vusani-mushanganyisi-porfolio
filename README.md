# 🌐 Personal CV Portfolio Website

## 📌 Project Overview

This project is a professional personal CV and portfolio website developed to showcase my academic background, technical skills, academic projects and career interests in Information Technology Management.

The website provides an online professional profile that allows potential employers, internship providers and other professionals to learn more about my skills, experience and IT-related projects.

The portfolio was developed using **Bolt.new** and is deployed online for public access.

---

## 👨‍💻 About Me

I am a **final-year Diploma in Information Technology Management student** with an interest in information technology, systems analysis, database management and IT project management.

My academic background has allowed me to develop both technical and problem-solving skills. I am particularly interested in applying technology to solve business problems and improve organisational processes.
